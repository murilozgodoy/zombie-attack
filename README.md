# Projeto Pygame - Jogo Zombie Attack

## Descrição do jogo
Em um mundo devastado por um apocalipse zumbi, um soldado solitário deve lutar pela sobrevivência. O objetivo é simples, mas desafiador: resistir por 2 minutos a uma onda implacável de zumbis. Mas não será uma tarefa fácil! Além de se proteger dos zumbis que atacam diretamente, o jogador deve impedir que os inimigos invadam sua base militar e desviar das bombas aéreas que caem a todo instante. A qualquer momento, hordas de mortos-vivos tentarão invadir sua fortaleza, e se algum deles chegar até o canto esquerdo, a sirene da base toca e o jogo acaba. O soldado enfrentará dois tipos de ameaças: carniçais de combate e corredores espectrais. O jogador precisa usar suas habilidades de combate e estratégia para resistir até o fim da onda e entrar no ranking de sobreviventes.

O cálculo da pontuação dos jogadores sobreviventes é: Vida + (% acertos de tiros * 200) + (zumbis mortos * 2).

## Como executar

Faça o download gratuito de Zombie Attack seguindo o passo a passo e tente sobreviver ao apocalipse zumbi!

1. Faça o download do arquivo clicando no botão abaixo.

2. Extraia o conteúdo do arquivo zip em uma pasta que preferir.

3. Tenha o Python instalado (a partir da versão 3.10)

4. Abra o terminal e navegue até a pasta onde você extraiu os arquivos.

5. Execute o seguinte comando: pip install pygame para obter a biblioteca pygame

6. Após a instalação, execute o seguinte comando para iniciar o jogo: python main.py

OBS: se estiver no windows, coloque a escala da sua tela em 100%
